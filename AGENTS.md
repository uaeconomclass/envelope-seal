# Анімація «Запечатуємо ваш лист» — бриф для Codex

## Що робимо
Банер-анімація для проєкту замовника (новорічна кампанія «Запечатываем ваше письмо… Планы внутри»). Сценарій:
1. Лист зі списком планів опускається у відкритий конверт.
2. Клапан конверта закривається, це справжній 3D-поворот.
3. Сургучний штамп злітає зі свого місця, тисне на конверт, з'являється печатка зі спалахом та іскрами.
4. Штамп повертається на місце. **Фінальний кадр має збігатися з `reference.jpg`.**

Технологія: шари PNG/WebP + CSS + GSAP 3.12.5 (cdnjs, точна версія). Без збірки, без фреймворків. Не GIF і не відео: анімацією має керувати код (запуск при скролі чи кліку, повтор, `prefers-reduced-motion`).

## Поточний стан (робоче демо)
- `index.html` — уся сцена й таймлайн. Стейдж має фіксований розмір 1280×691 px і масштабується через `transform: scale()` (функція `fit()`). Таймлайн лежить у глобальній `tl`.
- `reference.jpg` — оригінал дизайну 1280×691, еталон фінального кадру.
- `bg.jpg`, `env.png`, `seal.png`, `stamp.png` — шари, вирізані з reference скриптом `tools/prep.py` (OpenCV: маски + inpaint). Це тимчасові шари.
- `tools/frames.py` — візуальний контроль (див. нижче).
- Опубліковане демо: https://claude.ai/artifact/DWKWtGf1mrzsddJmiDVp9k

### Відомі дефекти демо (саме їх і треба прибрати)
1. У центрі конверта на місці вирізаної печатки розмита пляма, її видно, поки клапан відкритий.
2. Під конвертом і під штампом на фоні inpaint-«каша». Її видно, коли штамп злітає, і при 3D-нахилі конверта.
3. Внутрішня частина конверта й клапана намальована CSS-градієнтами, а не фотореалістично.
4. Лист намальований у HTML (шрифт Caveat) і не схожий на фото.
5. Мобільної версії немає: сцена просто зменшується.

## Задачі

### 1. Згенерувати чисті шари (image-генерація, `reference.jpg` як референс стилю)
Усі координати вказані в системі reference (1280×691). Віддавати у **2× розмірі** для retina, а в CSS лишати 1×. Формат PNG з прозорістю, наприкінці конвертувати у WebP. Освітлення має бути однакове на всіх шарах: теплий золотистий світ із центру, нічна сцена.

| Файл | Розмір 1× | Що це | Позиція на стейджі |
|---|---|---|---|
| `bg_clean` | 1280×691 | Сцена **без** конверта, штампа й тексту. Іскри-шлейфи навколо конверта лишити | 0,0 |
| `env_back_inner` | 418×275 | Внутрішня задня стінка відкритого конверта, темніша, з тінню зверху | 425,148 |
| `env_pocket` | 418×275, прозорий | Лицьова частина конверта **без** верхнього клапана: бокові й нижній клапани. Верхній край — V-виріз до точки (217,152) локально | 425,148 |
| `flap_outer` | 418×153, прозорий | Верхній клапан ззовні: трикутник, вершина (217,153) | 425,148 |
| `flap_inner` | 418×153, прозорий | Той самий клапан зсередини (його видно, коли він відкритий) | 425,148 |
| `seal` | 112×112, прозорий | Сургучна печатка із зіркою, як на reference | центр 642,300 |
| `stamp` | 180×195, прозорий | Штамп (дерев'яна ручка + латунна основа), ракурс як на reference | 705,5; центр основи локально (47,157) |
| `letter` | 350×200, прозорий | Аркуш паперу з рукописним списком: «Больше путешествий», «Финансовая подушка», «Инвестиции», «Меньше спонтанных покупок» з червоними галочками | у `#env` лівий-верх (34,40) |

Правила генерації:
- Кожен шар генеруй окремо, з `reference.jpg` як input image, і завжди вказуй «same lighting, same paper texture, same color palette as reference».
- `env_pocket` + `flap_outer` + `seal` поверх `bg_clean` мають давати картинку, візуально ідентичну reference.
- Прозорі краї без ореолу: перевір на чорному й білому тлі.
- Якщо генератор «пливе» в кольорі, підженеш фінальні шари під reference через color match (наприклад, histogram matching в OpenCV), а не перегенеровуй до безкінечності.

### 2. Підставити шари в `index.html`
- Замінити `bg.jpg` / `env.png` / CSS-градієнти `#back` і `#flap .b` / HTML-лист на нові шари. Координати й таймлайн не змінювати без потреби.
- Текст «Запечатываем ваше письмо… / Планы внутри…» винести з картинки в HTML: живий текст, адаптивний. Шрифт підібрати під reference (serif-заголовок, sans-підзаголовок, Google Fonts з кирилицею).

### 3. Мобільна версія (≤ 600px)
Вертикальна композиція 390×(~700): фон `bg_clean_mobile` (outpaint/кроп reference у вертикаль), конверт крупніше по центру, текст під ним. Той самий таймлайн, інші координати (окремий набір змінних або другий стейдж).

### 4. Збірка блоку для сайту
- Папка `dist/` — самодостатній блок: `envelope.html` (фрагмент без `<html>/<body>`), `envelope.css`, `envelope.js`, `assets/*.webp`.
- Запуск налаштовується атрибутом `data-trigger="load|inview|click"`, за замовчуванням `inview` (IntersectionObserver, програється один раз).
- `prefers-reduced-motion` — одразу фінальний кадр.
- Бюджет: усі ассети ≤ 1.2 MB (desktop) і ≤ 600 KB (mobile).

## Візуальний контроль (обов'язково після кожної зміни)
```
pip install playwright pillow numpy opencv-python && python -m playwright install chromium
python tools/frames.py
```
У `qa/` з'являться кадри `desktop_t*.png` у ключові моменти, `sheet.png` (усі кадри одним листом), `diff_final.png` (різниця фіналу з reference) і `mobile.png`. Звіт пишеться в `qa/report.txt`.

Переглянь `qa/sheet.png` і кожен кадр сам і пройди чекліст:
- [ ] Фінальний кадр збігається з reference: `envelope` diff < 4, `all` < 3. На `diff_final.png` немає яскравих плям.
- [ ] t=0…1.6: лист над конвертом, клапан відкритий. Видно внутрішню сторону клапана й конверта, плям і inpaint-каші немає.
- [ ] t=2.4: лист повністю всередині, верх листа видно лише у V-вирізі.
- [ ] t=2.8: клапан закривається без «стрибка» шарів, тінь від клапана природна.
- [ ] t=3.9: основа штампа стоїть по центру печатки (±3 px), печатку під штампом не видно до удару.
- [ ] t=4.3: печатка на місці, штамп повертається, на фоні під штампом немає артефактів.
- [ ] Краї вирізаних шарів без ореолів і сходинок, кольори шарів не відрізняються від сусідніх ділянок.
- [ ] `mobile.png`: нічого не обрізано, текст читається, горизонтального скролу немає (див. report.txt).
- [ ] Реальне відтворення в браузері: плавно, без ривків, 60 fps, без помилок у консолі.

Якщо змінюєш тайминги таймлайну, онови `TIMES` у `tools/frames.py`, щоб кадри потрапляли на ключові моменти.

## Граблі
- `page.evaluate('tl.pause()')` у Playwright **валить вкладку**: повертається об'єкт таймлайна, і він не серіалізується. Завжди закінчуй вираз на `; 0`.
- Без `<meta charset="utf-8">` локальний сервер віддає кирилицю кракозябрами.
- `clip-path` і `filter` на одному елементі: тінь обрізається. Тому тінь клапана висить на обгортці `#flapW`.
- Клапан — один елемент з `rotationX` 180→0. Сторона (outer/inner) і z-index перемикаються на 90° у `faces()`. Не додавай `preserve-3d` разом із `clip-path`: воно сплющиться.
